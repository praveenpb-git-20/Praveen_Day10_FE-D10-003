# Employee Dashboard UI Components

## Overview

Employee Dashboard UI Components is a responsive React application developed to demonstrate reusable UI components and modern frontend design principles. The project includes dashboard widgets, employee profile cards, and team information cards using React functional components and CSS.

---

## Features

* Responsive Dashboard Widgets
* Employee Profile Cards
* Team Information Cards
* Reusable React Components
* Modern UI Design
* Responsive Layout using CSS Grid
* Hover Animations and Smooth Transitions
* Clean and Professional Interface

---

## Technologies Used

* React.js
* JSX
* CSS3
* JavaScript (ES6)
* HTML5

## Components

### Dashboard Widgets

Displays important business information using reusable cards.

Current Widgets:

* New Clients
* Training Courses Completed
* Tasks Completed

Features:

* Icon support
* Custom colors
* Progress indicator
* Responsive design

---

### Employee Cards

Displays employee information in a modern profile card.

Information Included:

* Employee Initials Avatar
* Employee ID
* Employee Name
* Job Role
* Department
* View Profile Button

Features:

* Gradient header
* Professional card layout
* Hover animation
* Responsive design

---

### Team Information

Displays details about different teams.

Information Included:

* Team Name
* Team Lead
* Number of Members
* Team Icon
* View Team Button

Features:

* Modern card layout
* Responsive design
* Hover animation
* Professional styling
